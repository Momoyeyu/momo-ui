## 安装

需要 **React 19** 和支持 ESM 的前端构建工具。组件分发在 <a href={repo + '/releases'}>GitHub Releases</a>。

```sh
pnpm add https://momoyeyu.github.io/momo-ui/packages/momo-ui-0.1.0.tgz
```

使用 npm 的项目可用同一地址执行 `npm install`。也可<a href={release}>直接下载安装包</a>。

## 引入第一个控件

在应用入口引入一次样式，再按需导入组件。应用保存业务状态，组件接收值、标签和回调。

```tsx
import {useState} from 'react';
import {Field, Switch} from '@momoyeyu/momo-ui';
import '@momoyeyu/momo-ui/styles.css';

export function VoiceSettings() {
  const [enabled, setEnabled] = useState(false);
  return (
    <Field label="语音">
      <Switch label="语音" checked={enabled} onChange={setEnabled}/>
    </Field>
  );
}
```

## 本地维护

```sh
git clone https://github.com/Momoyeyu/momo-ui.git
cd momo-ui
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

组件文档保存在 `src/pages/components/`。新增组件时同步更新入口导出、MDX 文档和导航目录。
