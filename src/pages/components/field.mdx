## 用法

```tsx
import {Field} from '@momoyeyu/momo-ui';

<Field label="显示名称" htmlFor="display-name">
  <input id="display-name" name="displayName" />
</Field>
```

`label` 是可见行标签。单字段用 `htmlFor` 连接控件；一行多个操作时，分别给按钮可访问名称。`aside` 可放辅助节点，`children` 放右侧控件。焦点和校验由具体控件管理。
