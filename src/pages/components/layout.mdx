## 选择组件

- **Container** 居中并限制最大宽度。`width` 默认 `1120px`，`gutter` 默认 16 px，均接受 CSS 长度或百分比。
- **Stack** 纵向排列，相邻内容用 `gap` 控制，默认 `md`。用 `align` 调整横向对齐。
- **Cluster** 横向排列操作或标签，默认换行、垂直居中。使用 `wrap={false}` 保持单行。
- **Grid** 用 `columns` 设定等宽列数，默认一列。自定义的列宽或响应式布局可以通过类名覆写。
- **Surface** 为区域提供底色、描边和圆角。`tone` 取 `panel`、`inset` 或 `plain`，`padding` 控制内边距。
- **SectionHeading** 用 `title`、可选的 `description` 和 `level`（1–6）组织标题。`id` 会加在标题元素上。
- **Divider** 用于分隔相邻内容。**EmptyState** 展示加载、为空或失败等提示，可在调用方传入 `role="status"`。

间距档位为 `none`、`xs`、`sm`、`md`、`lg`、`xl`，对应 0、4、8、16、24、32 px。容器、堆叠、操作组、网格和面板可以用 `as` 保留页面的 HTML 语义。布局组件只渲染一层 DOM。

## React

```tsx
import {Cluster, Container, Grid, Stack, Surface} from '@momoyeyu/momo-ui';
import '@momoyeyu/momo-ui/styles.css';

<Container as="main" width="68rem">
  <Stack gap="lg">
    <Grid columns={2}><Surface>记事本</Surface><Surface>时钟</Surface></Grid>
    <Cluster>{actions}</Cluster>
  </Stack>
</Container>
```

## Vue

```vue
<script setup>
import {Container, Stack, Surface} from '@momoyeyu/momo-ui/vue';
import '@momoyeyu/momo-ui/styles.css';
</script>

<template>
  <Container as="main" width="1500px" gutter="6%">
    <Stack gap="md"><Surface>界面内容</Surface></Stack>
  </Container>
</template>
```
