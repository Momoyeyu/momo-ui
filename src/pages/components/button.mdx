## 用法

```tsx
import {Button, IconButton} from '@momoyeyu/momo-ui';

<Button type="submit" variant="primary">保存</Button>
<IconButton icon="settings" label="配置语音" onClick={openVoiceSettings} />
```

<table><thead><tr><th>参数</th><th>含义</th></tr></thead><tbody><tr><td><code>variant</code></td><td><code>primary</code>、<code>outline</code>（默认）、<code>ghost</code> 或 <code>danger</code></td></tr><tr><td><code>size</code></td><td><code>md</code>（默认）或 <code>sm</code></td></tr><tr><td><code>type</code></td><td>默认 <code>button</code>，提交表单时设为 <code>submit</code></td></tr><tr><td><code>IconButton.label</code></td><td>必填，为纯图标操作提供名称</td></tr><tr><td><code>IconButton.icon</code></td><td>从 <code>IconName</code> 中选择图标</td></tr></tbody></table>

支持 `disabled`、`onClick` 和 `aria-pressed` 等按钮属性。聚焦后按 Enter 或空格触发。

## Vue

```vue
<Button variant="primary" href="/download">下载</Button>
<Button variant="bare" class="deck-control" @click="next">下一张</Button>
```

从 `@momoyeyu/momo-ui/vue` 导入。官网的下载和指南链接使用共享按钮样式，封面与卡片的动作控件通过 `bare` 变体保留自己的几何和动画。
