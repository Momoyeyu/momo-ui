## 用法

`Panel` 接收可选的 `title`、`actions` 和子节点。`Dialog` 的背景与边框使用相同的视觉规则。

```tsx
import {Button, Dialog} from '@momoyeyu/momo-ui';

<Dialog open={open} label="语音设置" onClose={() => setOpen(false)}>
  <h2>语音设置</h2>
  {children}
  <Button onClick={() => setOpen(false)}>返回</Button>
</Dialog>
```

应用控制 `open`，通过 `label` 设置可访问名称。焦点范围与背景可访问性由 `dialog` 语义支持。Esc 调用 `onClose`，也可以放置明确的返回或关闭操作。
