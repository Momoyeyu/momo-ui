## 用法

```tsx
import {Slider} from '@momoyeyu/momo-ui';

<Slider label="语音" value={volume} onChange={setVolume} disabled={muted} />
```

`value` 范围为 0–100，`onChange` 接收新数值。滑条支持方向键和 Home、End。静音禁用滑条时可以继续传入保存的音量。
