## 用法

```tsx
import {Switch} from '@momoyeyu/momo-ui';

<Switch label="显示状态" checked={enabled} onChange={setEnabled} />
```

`checked` 传入当前状态，`onChange` 接收新值。`disabled` 禁止操作，`label` 为必填的可访问名称。键盘用 Tab 聚焦，空格或 Enter 切换。
